GATE DA DBMS and Algorithms Formula Sheet with Traps

By MD ANISH AHAMADUpdated 4 Oct 20267 min read

GATE DA's programming and database sections reward exact counts: comparisons, probes, nodes, edges, keys and cuboids. This sheet collects those formulas for algorithms and data structures, Python, relational databases and data warehousing. Each has its condition, a one-line example of my own and the trap beside it, all checked against the GATE DA 2027 book.

Key takeaways

  • Selection sort always makes n(n−1)2\displaystyle \frac{n(n - 1)}{2}2n(n−1)​ comparisons; insertion sort's shifts equal the number of inversions.
  • Dijkstra needs non-negative weights; Bellman–Ford allows negative ones and detects negative cycles.
  • Python floor division rounds towards minus infinity, and round sends ties to the even integer.
  • An attribute that never appears on a right-hand side belongs to every candidate key.
  • B+ tree order is a floor, never a rounded value.
  • nnn dimensions give 2n2^n2n cuboids, but ROLLUP forms only n+1n + 1n+1 groupings.

The terms this sheet uses

nnn is the number of elements and log⁡2\log_2log2​ the base-2 logarithm. Θ(f)\Theta(f)Θ(f) means "grows exactly like fff", and O(f)O(f)O(f) means "at most like fff". An inversion is a pair of elements in the wrong order. The load factor of a hash table is α=nm\displaystyle \alpha = \frac{n}{m}α=mn​, keys over slots.

In a database, a functional dependency X→YX \to YX→Y says that equal XXX values force equal YYY values. The closure X+X^+X+ is every attribute that XXX determines. A superkey determines all attributes, and a candidate key is a minimal superkey. A cuboid is one grouping of a data cube.

Python rules that decide answers

These are code, not formulas, but they decide answers just as exactly.

  • 7 / 2 is 3.5; -7 // 2 is -4; -7 % 2 is 1. The remainder takes the divisor's sign.
  • round(2.5) is 2 and round(3.5) is 4: ties go to the even integer.
  • range(a, b) and s[i:j] stop before the end; s[::-1] reverses.
  • After b = a, a += [3] changes b too, while a = a + [3] does not.
  • def f(x, L=[]) creates L once, so calls share and grow the same list.

Frequently asked questions

How many comparisons does binary search make in the worst case?

On a sorted array of nnn elements, binary search makes at most ⌊log⁡2n⌋+1\lfloor \log_2 n \rfloor + 1⌊log2​n⌋+1 probes, from the recurrence T(n)=T(n/2)+1T(n) = T(n/2) + 1T(n)=T(n/2)+1. For 100 elements that is 6+1=76 + 1 = 76+1=7. The array must be sorted and allow random access, so binary search on a linked list loses its advantage.

How do you calculate the order of a B+ tree?

An internal node with ppp pointers of PPP bytes and p−1p - 1p−1 keys of KKK bytes must fit in a block of BBB bytes, so pP+(p−1)K≤BpP + (p - 1)K \le BpP+(p−1)K≤B, which gives p=⌊B+KP+K⌋\displaystyle p = \left\lfloor \frac{B + K}{P + K} \right\rfloorp=⌊P+KB+K​⌋. With B=1024B = 1024B=1024, K=12K = 12K=12 and P=8P = 8P=8, the order is 51. Always take the floor, never round up.

How many cuboids does a data cube have?

With nnn dimensions and no hierarchies, a data cube has 2n2^n2n cuboids, one for every subset of dimensions. If dimension iii has LiL_iLi​ levels, not counting the top level all, the count is ∏i(Li+1)\prod_i (L_i + 1)∏i​(Li​+1). In SQL, GROUP BY CUBE over nnn attributes forms 2n2^n2n groupings, while ROLLUP forms only n+1n + 1n+1.

What is the result of -7 // 2 in Python?

In Python 3, -7 // 2 is -4, because floor division rounds towards minus infinity, not towards zero. The remainder -7 % 2 is 1, since the remainder takes the sign of the divisor. True division 7 / 2 gives 3.5. Also note that round(2.5) gives 2, because ties go to the even integer.

When is a decomposition lossless?

Splitting RRR into R1R_1R1​ and R2R_2R2​ is lossless exactly when the common attributes form a key of one side: R1∩R2→R1R_1 \cap R_2 \to R_1R1​∩R2​→R1​ or R1∩R2→R2R_1 \cap R_2 \to R_2R1​∩R2​→R2​ holds under the functional dependencies. A 3NF synthesis is always lossless and dependency-preserving. A BCNF decomposition is always lossless but may lose a dependency.
