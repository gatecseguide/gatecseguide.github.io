GATE DA Machine Learning Formula Sheet with Worked Lines

By MD ANISH AHAMADUpdated 4 Oct 20266 min read

The machine learning formulas you need for GATE DA cover regression, classification, decision trees, neural networks, model selection, clustering and PCA. This sheet gives each with its condition, a one-line example of my own and the trap beside it. Every formula is checked against the last-minute sheet in the GATE DA 2027 book.

Key takeaways

  • Least squares, ridge and PCA are linear algebra: learn the matrix forms, not only the scalar ones.
  • Ridge shrinks coefficients towards zero but never exactly to zero.
  • Logistic regression, LDA with a shared covariance and the perceptron all draw linear boundaries.
  • Entropy in bits uses log⁡2\log_2log2​; the logistic loss uses ln⁡\lnln.
  • Small kkk in k-nearest neighbour means high variance; large kkk means high bias.
  • Count network parameters layer by layer, and check whether biases are included.

The terms this sheet uses

The training data are nnn pairs (xi,yi)(x_i, y_i)(xi​,yi​). Each xix_ixi​ is a vector of features, and yiy_iyi​ is its label: a number in regression, a class in classification. XXX is the n×dn \times dn×d matrix of features, one row per example.

A model has a weight vector www and a bias bbb. The loss measures how wrong the predictions are, and training minimises it. η\etaη is the learning rate. ln⁡\lnln is the natural logarithm, and log⁡2\log_2log2​ is used wherever the answer is in bits.

The k-nearest neighbour rule takes a majority vote of the kkk closest points. With k=1k = 1k=1 the training error is zero. Scale the features first, and pick an odd kkk to avoid ties between two classes. XOR is not linearly separable, so no perceptron learns it; one hidden layer does.

In one line: PCA is an eigenvalue problem on the centred covariance matrix, so the linear algebra sheet does half the work.

Frequently asked questions

What is the formula for information gain in a decision tree?

Information gain is the parent's entropy minus the weighted entropy of the children: H(parent)−∑∣child∣∣parent∣H(child)\displaystyle H(\text{parent}) - \sum \frac{\lvert \text{child} \rvert}{\lvert \text{parent} \rvert} H(\text{child})H(parent)−∑∣parent∣∣child∣​H(child), with H=−∑pklog⁡2pkH = -\sum p_k \log_2 p_kH=−∑pk​log2​pk​. Entropy is 1 bit for a 50-50 split of two classes and 0 for a pure node. Use log⁡2\log_2log2​, because the answer is expected in bits.

How many parameters does a fully connected neural network have?

For layers of sizes n0,n1,…,nLn_0, n_1, \ldots, n_Ln0​,n1​,…,nL​, count ∑lnl−1nl\sum_l n_{l-1} n_l∑l​nl−1​nl​ weights, then add one bias for every unit after the input layer. A 4-3-1 network has 12+3=1512 + 3 = 1512+3=15 weights and 4 biases, so 19 parameters. Questions often ask for weights only, so read whether biases are included.

What is the margin of a hard-margin SVM?

The hard-margin SVM minimises 12∥w∥2\displaystyle \frac{1}{2}\lVert w \rVert^221​∥w∥2 subject to yi(w⊤xi+b)≥1y_i(w^\top x_i + b) \ge 1yi​(w⊤xi​+b)≥1, and the width of the margin is 2∥w∥\displaystyle \frac{2}{\lVert w \rVert}∥w∥2​. The support vectors lie exactly on yi(w⊤xi+b)=1y_i(w^\top x_i + b) = 1yi​(w⊤xi​+b)=1. Removing a point that is not a support vector leaves the solution unchanged, a fact worth knowing for statement-based questions.

What is the difference between k-fold and leave-one-out cross-validation?

In k-fold cross-validation you split the data into kkk folds, train kkk models each on k−1k - 1k−1 folds, and average the validation scores. Leave-one-out is the case k=nk = nk=n: it trains nnn models, each on n−1n - 1n−1 points. It is nearly unbiased but expensive and has high variance. Never tune on the test set.

How do you compute the variance explained by a principal component?

Centre the data and find the eigenvalues of its covariance matrix. The variance along component kkk is its eigenvalue λk\lambda_kλk​, and the share explained is λk∑jλj\displaystyle \frac{\lambda_k}{\sum_j \lambda_j}∑j​λj​λk​​. With eigenvalues 6, 3 and 1, the first component explains 60 per cent and the first two explain 90 per cent. PCA is sensitive to feature scaling.
